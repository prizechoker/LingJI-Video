# 第 1 集《棋盘之外》v2.2 分镜

全片写实三维（engine2：three.js 物理材质、HDRI、软阴影、AO、景深、AgX 调色），1080p / 30fps。
所有真人只出现手或逆光剪影，不出现面孔；历史机器按真实外形还原。

## 视觉规则

- **色彩**：人 = 暖色（钨丝灯、琥珀），机器 = 冷色（青白、钢蓝）。第六幕结尾冷暖交汇。
- **母题**：一颗黑子（第 37 手）、网格（棋盘 → 工厂地面 → 仓库二维码 → 洗碗机格架）、人手与机器手。
- **镜头**：慢推、慢移、微距景深；大动作用慢镜头。不用花哨转场，多用匹配剪辑（网格对网格、手对手）、硬切和切黑。
- **字幕**：底部居中衬线体，关键词金色/青色高亮，每次只出一行；左上角章节标签。
- **数据与引语**：直接在三维画面上排版（概率、比分、年份、引语），不另起二维图表页。
- **年代**：1979、1961 段落用档案胶片调色（低饱和、颗粒、轻微画面抖动、暗角）。
