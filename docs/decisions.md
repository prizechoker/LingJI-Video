## 2026-10-21 · 第一阶段确认

| 事项 | 决定 | 对后续的影响 |
|---|---|---|
| 编辑独立 | 内容独立、关系公开 | 涉及客户利益的内容须声明 |
| 人格载体 | 纯旁白，不出镜 | 原“实物实验”改为“可视化演示”（机器人视角、模拟、真实数据图解） |
| 结构 | “简史”拆成一整季，每期一个“难在哪” | 第一季规划按约 3 分钟单期重排（第二阶段完成） |
| 目标观众 | 大众：初高中生与普通人为主；不面向科研人员 | 工程细节只留一句结论或屏幕小字注释，不展开 |

| 时长 | 单一母版，约 3 分钟（2:00—3:30） | 旁白约 650—750 字；每期只讲一个核心洞见 |
| 版本与画幅 | 前期只做 16:9 通用版，不做多平台版本 | 字幕与关键图形按手机横屏观看放大，居中安全区构图 |
| 第一期路线 | 路线一为主，吸收路线三；路线二、四排除 | 路线三的“人形机器人”作为第一期结尾的转折，完整展开留给后续单期 |

| 第一期答案 | 机器人六十多年的成功，大多不是靠机器变聪明，而是靠人类把世界改造得足够简单；家，是最后一个改造不了的地方 | — |
| 写作原则 | 接受四条分层原则 + “传播四件套” | 每期立项时检查 |
| 风格比例 | B 为骨、C 为声、D 为锚、A 为光，强调分寸 | 悬念适度，不故弄玄虚；幽默来自事实本身，不油腻 |
